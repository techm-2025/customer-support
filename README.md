# Healthcare Booking Multi-Agent System (MAS)

## Overview
The [Agentic-healthcare-booking app repository](https://github.com/techm-2025/customer-support/tree/main/agentic-healthcare-booking-app) contains the complete implementation of a Healthcare Booking Multi-Agent System (MAS) built using Agntcy components and open-source Agentic AI. The system demonstrates multi-agent collaboration for healthcare appointment scheduling, symptom triage, and insurance policy management.

## Why Healthcare Booking MAS?

### High-Impact Healthcare Vertical
- Healthcare is a critical vertical for proving multi-agent collaboration capabilities
- Addresses real customer support challenges in the healthcare industry
- Provides early validation and integration opportunities for AI agent partnerships

### Market Validation
- ~46% of companies rank customer support as a top AI use case (as per a LangChain survey)
- Drives Agntcy adoption in the growing AI agent ecosystem

### Partnership Benefits
- Faster iteration through collaborative development
- Domain expertise from healthcare AI vendor partners
- Shared go-to-market (GTM) across the ecosystem
- Early integration and validation opportunities

## Key Technologies
- AGNTCY: Internet of Agents - open source framework to enable standardized discovery, orchestration, and collaboration between AI agents across different frameworks and platforms
- MCP (Model Context Protocol): Inter-agent communication
- A2A Communication: Agent-to-Agent messaging

## Implementation
- MAS Development - Core multi-agent system architecture
- A2A Communication - Agent-to-agent messaging
- MCP protocol - MCP tool calls
- AGNTCY OASF & Agent Directory - Agent record registry and discovery
- AGNTCY Identity - Authentication, agent cards, A2A support, Task-based Access Control (TBAC)
- AGNTCY Observability - Metrics, schema validation, runtime monitoring
